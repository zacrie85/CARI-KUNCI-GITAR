================================================================
CARI KUNCI GITAR (ChordKu) - PANDUAN PENGGUNAAN
Aplikasi deteksi & transposisi chord gitar untuk Windows
================================================================

1) APA YANG BISA DILAKUKAN APLIKASI INI
------------------------------------------------
- TRANSPOSISI CHORD: geser kunci lagu ke nada lain. Contoh: lagu
  "Pujaan Hati" (Kangen Band) aslinya kunci C; jika kamu ingin
  memainkannya dari kunci D, aplikasi menggeser seluruh chord:
  C G Am Em F Dm  ->  D A Bm F#m G Em
  Pustaka contoh di tab Transposisi kini berisi 7 lagu (Pujaan
  Hati + lagu tradisional + template kosong), bukan cuma satu.
- SEMUA KUNCI ALTERNATIF: menampilkan lagu yang sama di 12 kunci.
- SARAN CAPO: misal kunci D cukup pasang capo fret 2 lalu pakai
  bentuk chord kunci C.
- DETEKSI CHORD: menebak chord dari file audio/MP3/MP4 hasil
  unduhan YouTube, lengkap dengan estimasi kunci lagu.
  SEJAK v1.0.6 deteksi jauh lebih halus — perubahan chord
  tertangkap dari awal sampai musiknya habis (dulu lagu 4 menit
  bisa runtuh jadi 4 blok raksasa; sekarang progresi 12 chord
  terlacak 12/12 di tes), dan baris chord TIDAK dipotong lagi.
  Ada pilihan "Kehalusan deteksi": Kasar / Normal / Halus.
- LIRIK OTOMATIS (v1.0.5): setelah deteksi, klik "Kirim ke
  Transposisi + Lirik" — ChordKu mencari lirik lagu di layanan
  gratis lrclib.net memakai kolom "Judul lagu", lalu MENYUSUN
  sheet lengkap: baris chord di atas baris liriknya (align
  mengikuti waktu deteksi), intro ditulis "Intro : C G Am ...",
  kunci asal terisi otomatis — langsung siap di-transpose.
- JALUR ZAC DOWNLOADER (v1.0.7): ditempel penuh ke Zac Downloader
  v1.7.0+ — link dari browser Zac otomatis masuk Unduhan Bawaan &
  Browser YouTube tersemat, file hasil download Zac langsung
  masuk tab Deteksi (lihat bagian 9).
- ILUSTRASI CHORD: diagram fretboard (senar kayu + titik jari merah)
  untuk chord-chord dalam lagu, muncul otomatis di tab Transposisi
  dan tab Deteksi — tinggal ikuti cara menekan senarnya.
  v1.0.9: di tab Transposisi ilustrasi kini SEGERA muncul begitu
  sheet dimuat (Muat Contoh, Buka File .txt, tempel teks, atau kirim
  dari Zac) — tidak perlu menekan Transpose dulu; setelah Transpose,
  diagram ikut berganti ke chord kunci tujuan. Kanvas kosong
  menampilkan petunjuk, bukan area kosong.
- BROWSER YOUTUBE TERSEMAT: jendela browser sungguhan (mesin
  WebView2/Edge bawaan Windows) bisa dibuka dari dalam aplikasi —
  jelajahi YouTube seperti biasa, dan begitu halaman video terbuka
  URL-nya otomatis mengisi kolom Unduhan Bawaan.
- PENCARIAN MUSIK: alternatif tanpa browser — ketik judul/artis,
  klik hasil, URL mengalir ke Unduhan Bawaan yt-dlp.
- Tool eksternal seperti "Zac Downloader" tetap didukung (opsional).
- SIMPAN LAGU: menyimpan sheet chord ke database untuk dipakai
  lagi nanti, plus kamus jari chord dasar.

PENTING: hasil deteksi chord adalah PERKIRAAN (best-effort).
Selalu periksa kembali dengan telinga dan perbaiki manual bila perlu.

2) CARA CEPAT MENJALANKAN (dari kode sumber)
------------------------------------------------
a. Pasang Python 3.10+ dari https://www.python.org/downloads/
   (saat install, centang "Add Python to PATH").
b. Buka folder aplikasi, klik dua kali: setup.bat
   (memasang numpy dan yt-dlp otomatis).
c. Klik dua kali: jalankan.bat  -> aplikasi terbuka.
   (atau lewat CMD:  python chordku.py)

3) MEMBUAT FILE .exe (agar tinggal klik tanpa Python)
------------------------------------------------
a. Pastikan langkah 2 sudah berhasil.
b. Buka CMD di folder aplikasi dan jalankan: build_exe.bat
c. Hasilnya ada di folder dist\ChordKu.exe.
d. Catatan SmartScreen: saat pertama dibuka, pilih
   "More info" -> "Run anyway".

4) TAB YOUTUBE: BROWSER TERSEMAT + CARI MUSIK + UNDUH
------------------------------------------------
- BROWSER TERSEMAT (Zac Downloader di dalam ChordKu):
  1. Klik "Buka Browser YouTube" — jendela browser dengan mesin
     WebView2 (Edge) terbuka, menampilkan YouTube sepenuhnya.
  2. Jelajahi / login / cari lagu seperti di browser biasa.
  3. Begitu halaman video (URL berisi watch?v= atau youtu.be)
     terbuka, URL-nya LANGSUNG mengisi kolom "URL YouTube" di
     bagian Unduhan Bawaan — otomatis, tanpa salin-tempel.
  4. Klik "Download Audio (MP3)" seperti biasa.
  5. Kotak centang "URL video otomatis masuk Unduhan Bawaan"
     bisa dimatikan bila hanya ingin menonton.
  Syarat: WebView2 Runtime (sudah ada di Windows 10/11 hasil
  update normal). Jika tidak ada, gunakan tombol "Buka YouTube
  di Browser Sistem" sebagai jalan keluar.
- PENCARIAN TERINTEGRASI (tanpa membuka browser): ketik judul
  lagu / nama artis di kotak "Cari musik di YouTube" lalu klik
  "Cari". Klik-dua-kali hasil -> URL masuk Unduhan Bawaan.
  Daftar hasil muncul beserta channel dan durasinya.
- Kirim hasil ke unduhan bawaan:
  1. Klik-dua-kali salah satu hasil (atau pilih lalu klik
     "Pakai URL Ini -> Unduhan Bawaan") — URL langsung masuk ke
     kolom "URL YouTube" di bagian Unduhan Bawaan (yt-dlp).
  2. Klik "Download Audio (MP3)" — file MP3 tersimpan di folder
     downloads\.
  3. Mau lebih cepat? Klik "Download Langsung (MP3)" untuk
     mengunduh hasil terpilih tanpa langkah perantara.
- Butuh koneksi internet. Jika gagal karena pembatasan YouTube,
  coba perbarui yt-dlp:  pip install -U yt-dlp
- TOOL EKSTERNAL (sekarang OPSIONAL — pencarian sudah ada di atas):
  1. Klik "Pilih...", arahkan ke Zac Downloader.exe (atau
     shortcut-nya).
  2. Klik "Buka Tool Eksternal" -> unduh video musik lewat tool itu.
  3. Klik "Muat File Terakhir ke Deteksi" untuk mengambil file
     hasil unduhan ke tab Deteksi Chord.

5) DETEKSI CHORD (tab Deteksi)
------------------------------------------------
- Pilih file audio (.wav, .mp3, .m4a, .flac, dll) atau hasil
  unduhan YouTube.
- Pilih "Kehalusan deteksi" (v1.0.6):
  * Kasar  - perubahan chord jarang ditangkap (audio berisik).
  * Normal - seimbang, cocok untuk kebanyakan lagu.
  * Halus  - paling banyak perubahan chord tertangkap; pakai ini
    kalau hasil deteksi terasa "nyangkut" di satu chord saja.
  Deteksi kini berjalan sampai musiknya habis dan baris chord
  yang dikirim ke Transposisi tidak dipotong lagi (bug lama:
  hanya 64 chord pertama + "...").
- Klik "Deteksi Chord" dan tunggu beberapa saat.
- Hasil: urutan chord berwaktu + estimasi kunci lagu, dan panel
  "Ilustrasi chord yang terdeteksi" di bawahnya menampilkan cara
  menekan tiap chord (senar vertikal, titik merah = posisi jari,
  O = senar dibuka, X = tidak dipetik).
- LIRIK OTOMATIS (v1.0.5):
  1. Kolom "Judul lagu (untuk ambil lirik)" terisi otomatis dari
     judul unduhan YouTube atau nama file audio; koreksi saja
     bila salah ketik.
  2. Klik "Kirim ke Transposisi + Lirik" -> ChordKu mencari lirik
     di lrclib.net (API publik gratis, tanpa akun) dan menyusun
     sheet LIRIK + CHORD di tab Transposisi: baris chord tepat di
     atas baris liriknya mengikuti waktu deteksi, bagian sebelum
     lirik pertama menjadi "Intro : ...".
  3. Kalau lirik tidak ditemukan (judul salah / lagu belum ada /
     internet bermasalah), muncul pilihan "kirim CHORD SAJA".
  4. Lirik diambil on the fly untuk penggunaan pribadi — aplikasi
     tidak menyimpan file lirik di dalam paketnya.
- Tombol "Kirim ke Transposisi (chord saja)" tetap ada bila kamu
  hanya ingin chordnya tanpa lirik. Jika deteksi tidak
  menghasilkan chord sama sekali, muncul peringatan (coba audio
  yang lebih jelas).
- KONVERSI AUDIO: sejak v1.0.1, ChordKu.exe sudah MEMBAWA ffmpeg
  sendiri di dalamnya (di-bundle saat build), jadi file MP3, M4A,
  WEBM, FLAC, dan MP4 langsung bisa dideteksi tanpa memasang
  apa pun, dan unduhan YouTube otomatis dikonversi ke MP3.
- Jika kamu menjalankan dari KODE SUMBER (bukan exe) dan deteksi
  file non-wav gagal:
  1. Unduh ffmpeg dari https://github.com/BtbN/FFmpeg-Builds/releases
  2. Salin ffmpeg.exe ke sebelah chordku.py (atau tambahkan ke
     PATH Windows).

6) TIPS DETEKSI & TRANSPOSISI
------------------------------------------------
- Audio vokal/instrumen terlalu ramai = deteksi makin sulit.
  Gunakan audio sejelas mungkin (backing track/instrumen lebih
  baik daripada rekaman konser).
- Untuk lagu dengan kunci dasar sederhana (C, G, D, A, E), hasil
  deteksi biasanya paling akurat.
- Kalau lagu asli pakai kunci "sus/tambah nada", aplikasi
  menampilkan chord terdekat; lanjutkan secara manual.
- Transposisi juga bekerja untuk sheet dari situs chord: salin
  teksnya (termasuk lirik) lalu tempel di tab Transposisi. Kata
  lirik tidak akan ikut tergeser, hanya chord-nya.
- PUSTAKA CONTOH LAGU (v1.0.4): dropdown "Contoh lagu" di tab
  Transposisi berisi 7 pilihan — Pujaan Hati (Kangen Band), Rasa
  Sayange, Gambang Suling, Ampar-Ampar Pisang, Suwe Ora Jamu,
  Bintang Kecil, dan Template Sheet Kosong untuk lagu sendiri.
  Klik "Muat Contoh" -> lagu terpilih terisi dan "Kunci asal"
  otomatis mengikuti header lagunya.
- FORMAT SHEET YANG DIDUKUNG: chord di atas lirik, chord sejajar
  lirik ("C  G  lirik"), chord dalam kurung ("lirik [Am] lirik"),
  dan chord huruf kecil dengan suffix (am, em7, f#m, cmaj7) —
  gaya yang sering muncul di situs chord atau WhatsApp. Satu
  huruf kecil polos (a, c, e) tetap dianggap lirik.
- Jika tidak ada satupun chord dikenali, muncul peringatan yang
  menjelaskan format yang benar — hasil lama tidak ditimpa.
- Setelah transpose, lihat panel "Ilustrasi chord lagu ini" di
  bawah hasil: diagram fretboard untuk chord-chord unik dalam
  lagu (termasuk bentuk barre otomatis untuk chord seperti
  F#m, C#m, Bb — ditandai label "2fr", "4fr", dst).
- Tampilan v1.0.2 memakai tema futuristik merah-putih-emas.

7) STRUKTUR FOLDER
------------------------------------------------
chordku.py         : pemanggil utama aplikasi
app\              : kode program (engine, UI, deteksi, dll)
samples\          : contoh sheet chord (Pujaan Hati - kunci C)
downloads\        : hasil unduhan audio dari YouTube
requirements.txt   : daftar pustaka Python yang perlu dipasang
build_exe.bat      : membuat ChordKu.exe (PyInstaller)
setup.bat          : memasang dependensi
jalankan.bat       : menjalankan aplikasi dari kode sumber
chordku.db         : database lagu tersimpan (dibuat otomatis)
config.json        : pengaturan (dibuat otomatis)

8) MASALAH UMUM
------------------------------------------------
- "yt-dlp belum terpasang"  -> jalankan setup.bat, atau
  pip install -U yt-dlp
- "Format .webm/.mp3 butuh ffmpeg" -> pakai ChordKu.exe v1.0.1
  ke atas (ffmpeg sudah ter-bundle di dalam exe). Menjalankan
  dari kode sumber? Pasang ffmpeg (lihat bagian 5).
- Jendela tidak terbuka     -> jalankan dari CMD: python chordku.py
  agar pesan galat terlihat; kirim pesan galat itu saat melapor.
- SEMUA CHORD BERSUFFIX 7 (Amaj7, Dmaj7, C7...) -> sudah DIPERBAIKI
  di v1.0.8: (a) bug template chord 7 (nada ke-7 tertukar mayor-6),
  (b) kompresi chroma yang terlalu menggembungkan harmonik lemah,
  (c) penalti kecil utk kualitas extended. Kini chord 7 SEJATI
  (C7, Dmaj7, Am7) tetap terdeteksi benar, sedangkan triad biasa
  (C, G, Am, F) tidak lagi salah jadi 7.
- HASIL DETEKSI TERDENGAR SALAH -> wajar (perkiraan). Ubah manual
  atau transpose dari kunci yang kamu yakini benar.

9) TERINTEGRASI ZAC DOWNLOADER (v1.0.7)
------------------------------------------------
ChordKu kini ditempel sepenuhnya ke dalam Zac Downloader v1.7.0+
(tombol "Buka ChordKu" di panel kiri Zac Downloader). Semua fitur
Zac Downloader tetap utuh, dan ada 3 jalur otomatis:

- JALUR LINK: di browser Zac Downloader klik tombol
  "🎸 Kirim ke ChordKu" -> URL halaman otomatis masuk kolom
  "URL YouTube" (Unduhan Bawaan) DAN Browser YouTube tersemat
  ChordKu terbuka langsung di video itu.
- JALUR BROWSER: halaman hub ChordKu di Zac Downloader memuat
  tombol kirim per-mode (Unduhan saja / Browser saja / keduanya).
- JALUR FILE: setiap file MP3/MP4 di "Hasil Download" Zac
  Downloader punya tombol 🎸 -> file langsung masuk tab Deteksi
  ChordKu dan (bila "Auto-deteksi file dari Zac" aktif, default)
  deteksi chord langsung berjalan sampai akhir lagu.

Komunikasi memakai folder file JSON %APPDATA%\ZacChordKuBridge
(tanpa internet, tanpa port). ChordKu menandai kehadirannya lewat
status.json — Zac Downloader menampilkan "ChordKu: AKTIF".

10) HAK CIPTA
------------------------------------------------
Aplikasi ini hanya alat bantu belajar musik. Video/audio yang
diunduh dari YouTube tetap milik pemilik hak ciptanya. Gunakan
untuk keperluan pribadi/pendidikan, bukan untuk didistribusikan.
